Everything on these maps is also published as JSON next to the pages, so you can reuse it in your own charts or notebooks.

Files

FileContents
data/summary.jsonWhen the data was fetched, and one entry per repository: stars, stargazers read and located, number of countries, language, description
data/_all.jsonStats for all repositories together, counting each stargazer once
data/<repo>.jsonStats for one repository

Stats format

Each stats file has the same shape:

{
  "stargazers": 412,          // stargazers read
  "located": 268,             // ...with a location found on the map
  "countries": [              // most stargazers first
    {"code": "FR", "name": "France", "count": 57}
  ],
  "places": [
    {"label": "Paris, France", "country": "FR",
     "lat": 48.85, "lon": 2.35, "count": 31}
  ]
}

Country codes are ISO 3166-1 alpha-2. A place with "country_only": true stands for stargazers who gave only a country. When a repository couldn't be read on the last run, its file keeps the previous stats and adds error and stale_since.

From Python

import json, urllib.request

url = "https://<this site>/data/_all.json"
stats = json.load(urllib.request.urlopen(url))
for c in stats["countries"][:5]:
    print(c["name"], c["count"])
